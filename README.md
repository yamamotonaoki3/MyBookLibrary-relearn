# MyBookLibrary 学習プロジェクト

## 目的

以前AIで開発したMyBookLibraryを、自分の手で一から実装し直す。
完成だけでなく、実装の理由や処理の流れを自分の言葉で説明できることを目指す。

## フォルダ構成

- `app/`: 自分で実装するアプリ。構成や技術を確認してから実装を始める。
- `docs/learning-log.md`: 学習の記録、疑問、次の課題。
- `AGENTS.md`: この学習プロジェクトでのAIの支援方針。
- `CLAUDE.md`: Claude Code向けのルール参照。

元のMyBookLibraryは元の場所に残し、動作確認や実装後の比較に使用する。

元のプロジェクトの保存場所: `C:\web_application_files\MyBookLibrary`
調査結果と技術選定（PostgreSQL 18 + Drizzle + Docker Compose）は `docs/original-project-survey.md` を参照。

## 進め方

1. 元のアプリの機能と、使っている技術を確認する。
2. 最初に実装する小さな機能を選ぶ。
3. 期待する動作と完了条件を言葉にする。
4. 自分で実装し、困ったら段階的なヒントを受ける。
5. 動作確認とレビューを行い、学習記録を残す。

## Git管理

学習用の実装と資料もGitで管理する。小さな機能が動いた時点を目安にコミットし、変更理由を残す。
親フォルダが既にGit管理されている場合は、その管理を利用し、このフォルダ内に重ねてリポジトリを作らない。
GitHubへの公開は別途判断する。秘密情報や実データはコミットしない。
